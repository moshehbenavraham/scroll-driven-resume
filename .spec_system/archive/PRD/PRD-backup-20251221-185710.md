# Modern Resume Site - Product Requirements Document

## Overview

A scroll-synchronized frame animated parallax portfolio combining cinematic video sequences with parallax layering for a premium personal tech portfolio experience. The site features two hero sections with frame animation backgrounds controlled by scroll position, plus multi-layer parallax effects creating dimensional depth.

## Goals

1. Create a premium, single-page personal tech portfolio with cinematic motion effects
2. Implement scroll-synchronized frame animation for video-like experiences without autoplay
3. Layer parallax effects to create dimensional depth and premium feel
4. Showcase both personal brand and AI Community product with dedicated hero sections

## Technical Stack

- **Frontend Framework**: Next.js (via Firebase Studio)
- **Asset Storage**: Self-hosted Docker Stack (MinIO + PostgreSQL + Nginx)
- **Image Format**: WebP frame sequences for scroll-synchronized animation
- **Video Generation**: Google Flow (Veo 3.1)
- **Image Generation**: Google Whisk + Nano Banana Pro
- **Frame Extraction**: EZGIF
- **Hosting**: Firebase App Hosting

## Key Features

### Technology 1: Scroll-Synchronized Frame Animation

- Video converted to individual WebP frames (~240 frames per sequence)
- JavaScript maps scroll position to frame index
- Formula: scrollPercent x totalFrames = currentFrame
- Frames swap using opacity switching for smoothness

### Technology 2: Parallax Layering

- Background layers move at 0.3x-0.5x scroll speed
- Foreground elements move at 1x or faster
- Text overlays and UI elements have independent movement rates
- Creates perceived depth without true 3D

## Performance Requirements

- Target 60fps scroll performance
- Preload hero frames before reveal
- Lazy load product section frames
- Use RequestAnimationFrame for scroll handlers
- Maximum 5 active parallax layers at once
- Core Web Vitals: LCP < 2.5s, CLS < 0.1, FID < 100ms
