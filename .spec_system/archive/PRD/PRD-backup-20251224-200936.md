# modern-resume-site - Product Requirements Document

## Overview

Modern animated portfolio/resume website with WebGL effects, parallax scrolling, and interactive sections

## Goals

1. Create a visually stunning portfolio that showcases skills and projects
2. Implement smooth animations and WebGL effects for an immersive experience
3. Ensure excellent performance, accessibility, and mobile responsiveness

## Technical Stack

- Next.js 16.1.0 with Turbopack
- React 19.2.3
- TypeScript 5.x
- React Three Fiber (WebGL/3D)
- Framer Motion (animations)
- Tailwind CSS 4.x
- Zustand (state management)
- Vitest (unit testing)
- Playwright (E2E testing)
